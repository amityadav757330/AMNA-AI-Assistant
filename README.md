# AMNA AI Assistant

AMNA is a personal AI voice assistant developed by Amit Yadav.

## Features

- Voice Commands
- English & Hindi Speech Recognition
- Edge TTS Voice
- Ollama Integration
- Internet Search
- Memory
- Weather
- Wikipedia Search

## Tech Stack

- Python
- Ollama
- Edge TTS
- SpeechRecognition
- Pygame
- PyCharm
